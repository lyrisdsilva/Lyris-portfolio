Product · 2026

Zenwood

A keyboard you can click through.

Role
Design & front-end
Client
Concept project
Timeline
3 weeks
Tools
Figma, Claude, React, CSS

Overview

Zenwood turns a calm, wood-toned mechanical keyboard into the navigation for a product site. Every key is a door into a different part of the story.

The challenge

Make an interface that feels tactile and playful without hiding the content. Visitors had to understand in seconds that the keys are the menu.

What I did

  • Sketched the keyboard layout as a site map before drawing a single pixel
  • Prototyped key presses in Figma, then rebuilt them in CSS with real depth and springy timing
  • Used Claude to pair-program the interaction logic and test edge cases
  • Kept every key a real button, so it works with a keyboard and screen reader

Outcome

A small, fast site that people actually play with. It became the starting point for this portfolio.
