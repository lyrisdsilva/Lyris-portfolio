Overview

A Django web app that screens for heart disease, diabetes and pneumonia early, using machine learning models built on patient records.

The challenge

Early screening involved many manual steps. The aim was to automate the first check from symptoms and records, while keeping a clear path to a human review.

What I did

  • Designed the SQL data model for patient records
  • Built machine learning models on that data to automate early screening for the three conditions
  • Served predictions through a Python/Django app with REST APIs
  • Designed a dual-path health-check workflow for automated symptom analysis

Outcome

Manual diagnostic steps reduced by 70%, with predictions available straight from the web app.
