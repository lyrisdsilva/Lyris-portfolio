The Retro Portfolio Machine

A retro machine that types my story.

Role
Concept, design & build
Client
Personal
Timeline
2 weeks
Tools
Figma, Claude, HTML, CSS, JavaScript

Overview

This site. A yellow retro computer whose nine keys spell PORTFOLIO, with a screen that types my story on a loop.

The challenge

Fit live HTML keycaps onto a photographed device in perspective, so they line up perfectly at every screen size.

What I did

  • Measured every switch in the photo's own pixels and positioned caps as percentages
  • Built sculpted keycaps from layered gradients and a single animatable "lift" value
  • Wrote a tiny typing engine that tells the story and echoes whatever visitors type
  • Respected reduced-motion settings and made every key keyboard-accessible

Outcome

A one-page portfolio with personality that still loads fast and works on phones.
