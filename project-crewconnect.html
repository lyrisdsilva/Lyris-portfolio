CrewConnect

Mobile-first crew management for maritime teams.

Category
Full-stack
Built with
Full-stack web app, REST APIs, Real-time messaging
Key result
Real-time messaging and notifications for crews

Overview

A mobile-first system for managing ship crews: profiles, leave and work-from-home requests, document sharing and notices, all in one place.

The challenge

Crews work across ships and time zones, so requests, documents and updates were easy to lose.

What I did

  • Built crew profiles, leave/WFH requests, document sharing and notices
  • Designed it mobile-first for crew members on the move
  • Built REST APIs plus real-time messaging and notifications
  • Added meeting scheduling to support crew communication

Outcome

A single place for crew communication, requests and documents that works on a phone.
